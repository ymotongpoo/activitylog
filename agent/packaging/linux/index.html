activitylog apt repository

Debian and Ubuntu packages for amd64 and arm64:

  • activitylog-agent: desktop and terminal activity collection.
  • otelcol-extra: Discord, Slack, and SwitchBot components with metrics forwarded to a local Grafana Alloy instance over OTLP.
sudo curl -fsSL https://ymotongpoo.github.io/activitylog/apt/activitylog.gpg \
  -o /usr/share/keyrings/activitylog.gpg
echo "deb [signed-by=/usr/share/keyrings/activitylog.gpg] https://ymotongpoo.github.io/activitylog/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/activitylog.list
sudo apt update
sudo apt install activitylog-agent

After its release is published, install the combined Collector with sudo apt install otelcol-extra. The discord-otelcol transitional package upgrades existing installations.

Register credentials with sudo otelcol-extra-set-credentials discord or sudo otelcol-extra-set-credentials switchbot, then copy the required snippets from /usr/share/otelcol-extra/examples/ to /etc/otelcol-extra/conf.d/. Run sudo systemctl daemon-reload and sudo systemctl enable --now otelcol-extra. A fresh installation does not start the service. Only configured components need credentials.

Credentials are stored encrypted and decrypted by systemd when the service starts. See the Collector installation and migration instructions.
