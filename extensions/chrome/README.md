# activitylog Chrome 拡張

Chromium 系ブラウザ（Chrome、Edge、Brave、Arc、Vivaldi など）で、アクティブなタブの URL とタイトル、ブラウザのフォーカス状態をローカルの `activitylog-agent`（既定 `http://127.0.0.1:5610`）へ送る Manifest V3 拡張。
送信先は手元のエージェントだけで、Grafana Cloud へは直接送らない。プライバシールール（URL の切り詰めやドメインの除外）はエージェント側で適用される。

## インストール（パッケージ化されていない拡張として読み込む）

1. `chrome://extensions`（Edge は `edge://extensions`、Brave は `brave://extensions`）を開く。
2. 右上の「デベロッパー モード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリ（`extensions/chrome`）を選ぶ。
4. シークレットウィンドウも記録したい場合は、拡張の詳細画面で「シークレット モードでの実行を許可する」を有効にする。

## 送信するタイミング

- タブの切り替え、アクティブなタブの URL・タイトル・音声再生状態の変化
- ウィンドウのフォーカス変化（ブラウザがフォーカスを失ったら `focused: false`）
- ブラウザの起動時と拡張のインストール時
- ブラウザがフォーカスを持っている間は 30 秒ごと（ハートビート。MV3 の `chrome.alarms` の最小間隔）

`chrome://` などの内部ページもそのまま送る。除外するかどうかはエージェントのプライバシールールで決める。
エージェントが起動していなくてもエラーは出ない（2 秒でタイムアウトして破棄する）。

## 設定

拡張の「オプション」で次を変更できる。

- エージェントの URL（ポート番号だけでも可）。`127.0.0.1` と `localhost` のみ対応。
- ブラウザ名。UA Client Hints で Chrome / Edge / Brave / Opera を自動判別し、Vivaldi はタブの独自プロパティで判別する。Arc は判別できないので、必要ならここで `arc` を選ぶ。

「接続テスト」は `GET /v1/status` を呼んでエージェントの名前とバージョンを表示する。

## OS ごとの位置付け

- macOS: 拡張がなくてもエージェントは AppleScript で URL を取得できるが、この拡張を使うほうが望ましい。AppleScript は自動化の権限が必要で、シークレットウィンドウや音声再生状態を正確に取れず、ポーリングの負荷もかかる。拡張の報告が 90 秒以内にあればエージェントはそちらを優先する。
- Linux: ブラウザの URL を取得する手段はこの拡張だけ。URL やタブ単位の記録が必要なら必須。
